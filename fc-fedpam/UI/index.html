Bayestitch.

We present a visualizer that generates interactive Bayesian networks from input files. The structures are created as a result of FedPAM algorithm integrated into FeatureCloud and supports both static and dynamic Bayesian network visualizations. It also allows the user to analyze and modify the network structure in addition to performing inference on test data using the uploaded model.
